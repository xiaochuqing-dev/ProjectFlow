# ProjectFlow

ProjectFlow is a developer-focused productivity platform that turns project work into reusable engineering assets. It combines project spaces, Kanban tasks, structured dev logs, Markdown import, and AI-generated reflections to help students and independent developers document progress, review technical decisions, and prepare portfolio-ready project materials.

## Product Scope

ProjectFlow V1 focuses on a complete local-first portfolio workflow:

1. Create a project space.
2. Manage project tasks through a clear Kanban workflow.
3. Record structured development logs.
4. Import Markdown dev logs generated by Codex, Claude Code, or other AI coding tools.
5. Generate weekly reports, project summaries, and resume-ready project bullets.
6. Export Markdown for GitHub READMEs, resumes, and project documentation.

ProjectFlow is not a public SaaS product in V1. It is designed as a multi-user system for engineering depth, but the first release is optimized for personal use and GitHub portfolio presentation.

## V1 Features

- JWT authentication with user-level data isolation.
- Project spaces with status, tech stack tags, repository links, and project metadata.
- Kanban tasks with Backlog, Todo, In Progress, Review, and Done states.
- Structured dev logs with completed work, bugs fixed, decisions, problems, next steps, and reflection.
- Markdown paste import with front matter parsing and preview before saving.
- AI reflection outputs for weekly reports, project summaries, resume bullets, and README sections.
- Markdown copy and `.md` download export.
- Demo data based on InsightWrite 2.0.

## Deferred Features

- GitHub OAuth or GitHub App integration.
- Automatic commit, issue, or pull request sync.
- Team collaboration.
- Drag-and-drop task ordering.
- PDF or Word export.
- CLI import tool.
- Public hosted SaaS deployment.

## Language and Design Direction

ProjectFlow uses a professional developer-dashboard layout:

- The product UI is Chinese-first, with English technical terms where they are natural.
- GitHub README, repository metadata, and portfolio-facing technical docs stay English-first.
- A persistent left sidebar appears across authenticated pages.
- Pages may add their own top navigation for tabs, filters, search, and scoped actions.
- The interface favors restrained colors, strong spacing, dense but readable content, and clear state indicators.
- The visual reference is closer to Linear, Notion, and developer admin tools than a marketing site.

See [docs/ui-design-direction.md](docs/ui-design-direction.md) for the current design blueprint.

## Local Development

For Windows local startup, double-click `start-projectflow.bat` from the repository root. It runs in one console window, starts PostgreSQL and Redis with Docker Compose, builds the frontend, starts the backend and frontend, then opens the browser at `http://localhost:3000/login`. Press Enter in that console window to stop ProjectFlow.

Manual verification commands:

```powershell
cd frontend
npm.cmd run build
cd ..\backend
C:\Users\Administrator\Desktop\apache-maven-3.9.9\bin\mvn.cmd -q test
```

Current Windows environment notes:

- Maven is available through `C:\Users\Administrator\Desktop\apache-maven-3.9.9\bin\mvn.cmd`.
- Docker Desktop is required for PostgreSQL and Redis.
- If Docker Desktop is not running, the startup script tries to start it and waits before opening the browser.
- If npm installation hangs, clear or replace the local frontend dependency cache before rerunning `npm.cmd install`.
