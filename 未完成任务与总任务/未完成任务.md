## 全局风险

1. 编译风险：新增文件涉及 `ModelGatewayService.callJson`、`StringListConverter`、`SedimentAction` 枚举等依赖，这些类如果在 master 上不存在或签名不同，代码无法编译。
2. 数据库迁移：`ChangeBatch` 和 `DevelopmentSegment` 增加了新字段，`ProjectCapabilityCard` 是新表，没有对应的 migration 脚本（Liquibase/Flyway），启动时 JPA 自动 DDL 可能产生意外行为。
3. 前端 API 对接：`api.ts` 中新增了 `analyzeProjectCapabilities`、`listProjectCapabilityCards`、`updateCapabilityCard` 三个函数，对应后端端点路径是否完全匹配未验证。
4. 零测试运行记录：虽然写了测试文件，但没有跑过一次完整测试，实际通过率未知。
