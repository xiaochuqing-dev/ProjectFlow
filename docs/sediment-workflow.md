# Sediment Workflow

ProjectFlow V3.3.6 uses analysis batches as the processing boundary.

The workbench shows only the latest batch summary. The sediment processing center groups batches into today, yesterday, this week, and earlier. A batch reports commits, files, Agent results, model state, formal suggestions, local drafts, processed items, pending items, and ignored items.

Formal model suggestions are processed one at a time. The user can create a sediment, merge into an existing sediment, add evidence only, ignore, skip to the next item, or defer the item. Confirmation immediately removes the item from the pending queue and returns the target sediment, evidence increase, involved-file count, summary change, capability-analysis state, and direct navigation path.

Local fact and Agent-result drafts remain separate. They have no strong recommendation and never automatically become formal suggestions. Users can inspect them, rerun model analysis, or organize them manually later.
